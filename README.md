# Ramakrishna Marathi — QA Engineer Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript. It is ready to deploy with GitHub Pages.

## Files
- `index.html` — page content and project details
- `style.css` — responsive styling
- `script.js` — mobile navigation and placeholder-link guidance

## Before publishing
1. Open `index.html`.
2. Replace every `href="#"` link with your real GitHub, LinkedIn, repository and YouTube URLs. Search for `data-placeholder` to find them.
3. Update the project descriptions if your repositories or test counts have changed.
4. Replace the three "VIDEO COMING SOON" demo placeholders with links or embedded videos after publishing your demonstrations.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-github-username.github.io` (for a user site).
2. Upload all four files (`index.html`, `style.css`, `script.js`, `README.md`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the Pages deployment to finish. Your site will be at `https://your-github-username.github.io/`.

If you use a repository with another name instead, the URL will usually be `https://your-github-username.github.io/repository-name/`.
